Question 1 — Missing Roll Number

📖 Problem Statement

Ravi is a class monitor responsible for attendance. He has a list of roll numbers of students who submitted their assignment, out of n total students numbered 1 to n. Exactly ONE student did not submit. Given the list and the value of n, find the roll number of the student who did NOT submit.

📥 Input Specification

  • Line 1: Space-separated integers representing the roll numbers who submitted.
  • Line 2: An integer n, the total number of students (numbered 1 to n).

📤 Output Specification

Print a single integer representing the missing roll number to standard output.

💡 Worked Examples

⚠️ Constraints

  • 1 ≤ n ≤ 100,000
  • List contains exactly n - 1 distinct integers
  • All roll numbers are in the range [1, n]
  • Exactly one roll number is missing
